This analytics explores retail transaction data to identify purchasing behaviors, product affinities, and actionable insights for merchandising, inventory planning, and marketing strategy.
The dataset spans 2010–2011, containing 522,064 original records, later refined to 517,735 cleaned records after preprocessing.

This project implements a complete end‑to‑end analytical workflow—data exploration, cleaning, transformation, visualization, and association rule mining—to uncover meaningful purchasing relationships within real‑world retail data. By combining structured preprocessing with algorithmic techniques, the analysis provides a practical demonstration of how Market Basket Analytics can drive business insights.
